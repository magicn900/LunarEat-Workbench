# 使用指南


任务支持多位共同负责人。在任务编辑中勾选账号，同一任务会出现在各负责人的成员排期中，共享状态和日期，并非多份副本。“只看我的”包含共同负责的任务；具有任务更新权限的任一负责人均可更新状态、说明和阻塞原因，重新分配仍需排期管理权限。不选择负责人则为未分配。旧版单负责人记录自动兼容。

## 任务排期

在「项目共享 → 任务排期」查看团队近期安排。默认按负责人展示两周时间轴，可切换四周、上一段/下一段日期、只看我的，以及任意任务及其后代的范围。无日期任务在「待排期」中；已设置日期的未分配任务在「未分配」成员组中。

大目标和小任务使用同一种任务模型，通过父子关系拆分，不设独立阶段类型或固定层数。「任务树」展示完整结构，包括当前日期范围之外的任务；每个任务都可以独立设置负责人、日期、状态、说明和完成标准。详情抽屉支持添加子任务、调整父任务或提升为顶层任务。成员视图也按父子关系缩进排列：父任务显示名称、子任务完成数和底部括线，可折叠。跨负责人的上级任务作为浅色上下文行显示，不重复计入该成员的任务数量；完整结构可切换到任务树查看。

- 日期可同时留空；设置时开始日期不能晚于结束日期。拥有排期管理权限时，拖动任务条平移日期，拖左右两端调整起止日期；按天吸附，松开保存，Esc 取消。聚焦任务条或端点后可用左右方向键微调一天，保存后可撤销最近一次改期。父任务改期只改变自身日期，不自动移动子任务；详情表单仍可精确输入日期。
- 待开始、进行中、阻塞、已完成使用独立的深浅主题状态色，并保留状态文字与图例。改期请求失败或版本冲突时提示核对，并重新读取服务器数据，不静默覆盖他人的修改。
- 子任务超出上级日期只提示，不修改任何其他任务。负责人不从父任务自动继承。
- 阻塞任务需填写原因。子任务全部完成后父任务显示待验收，仍需手动确认完成；存在未完成后代时不能完成父任务，重开子任务前需先重开已完成的上级。
- 删除只允许没有子任务的任务；不会级联删除。移动不能形成循环。
- 排期存入项目共享数据库，独立于个人草稿、设计发布和实现同步。页面每 15 秒及重新获得焦点时刷新；多人同时修改同一任务会拒绝旧版本覆盖，并保留当前输入供处理。
- 成员停用或移出后，原任务负责人保留显示为不可分配，管理者可重新分配。归档项目中的排期只读。

新增三个独立权限：查看任务排期、更新自己负责的任务、管理任务与排期。本人更新仅允许改状态、说明和阻塞原因；分配、日期、层级、完成标准及创建/删除需要管理权限。已有明确授权的成员不会自动获得新增权限，请由管理员在项目权限中勾选。没有设计查看权限的成员，也可从开始使用页面打开已授权的任务排期。
## 我的草稿

每个账号在每个项目中都有自己的草稿。页面和结构化集合都属于草稿；编辑会自动保存，尚未发布的内容不会成为团队正式设计。

用页面顶部工具栏插入链接、文档或集合视图，也可以在空段落输入 /，再搜索和选择命令。视图中的编辑直接修改原对象，不会生成另一份数据。列头漏斗可以筛选、排序，视图底部可以调整分页。

右键菜单提供相关操作；Ctrl+Z 撤销，Ctrl+Shift+Z 重做。人工和 Agent 修改都进入同一套内容历史。同一编辑过程被其他页面的修改打断时，会拆成独立撤销步骤，避免撤销其他页面的内容。若已有历史记录混入了其他页面的修改，系统会拒绝不安全的撤销或重做；可以在“发布变更”中逐项检查并丢弃需要恢复的内容，不会自动重写历史。

## LaTeX 公式

“插入”菜单和斜杠命令提供行内公式、独立公式；也可在正文键入 $x^2$，或在空段落键入 $$ 后按 Enter 创建独立公式。对应插入动作可在设置 → 快捷键中绑定，默认不占用组合键。

点击公式或用左右方向键进入后，原位置直接显示可编辑源码，旁侧显示实时预览，无需应用或取消。改动沿用正文自动保存与撤销分组；光标离开时恢复公式显示，Esc 只退出编辑、不撤销输入。独立公式内 Enter 换行，行内公式内 Enter 离开公式；清空源码后按 Backspace / Delete 可删除整条公式。

Markdown 保存行内 $...$ 和独立的多行 $$ 定界公式，保留 LaTeX 源码，不存预览 HTML；只读文档嵌入也显示公式。代码区不解析公式，普通美元符号使用反斜杠转义。预览支持常用数学公式，不支持完整 LaTeX 文档编译、外部宏包或公式编号引用。

语法错误、超长公式或预览线程不可用时只显示该公式的源码与提示，仍可编辑、删除和保存。预览不访问公式指定的外链、图片或 HTML，宏展开、尺寸和执行时间受限；限制只影响显示，不阻断源码保存。错误详情会出现在实时预览中，离开公式后悬停警告可查看。

## 行内格式与快捷键

正文工具栏的加粗、斜体旁提供高亮和删除线。选中文字后点击切换，再次点击取消；高亮使用随主题适配的单色底色。源码中的高亮语法为 `==文字==`，删除线为 `~~文字~~`；代码区域和转义后的等号保持原文。格式随正文保存，支持原有撤销、只读文档嵌入和 Markdown 导出。源码编辑入口仍可用于恢复无法渲染的内容。

设置 → 快捷键可查看作用域、修改或清除绑定，也可恢复单项或全部默认。点击“修改”后按下组合键即可保存；Esc 取消录入。同一作用域冲突、常见浏览器保留键或可能影响普通文字输入的绑定会被拒绝。高亮、表格和图片默认不绑定，按需设置。

绑定随账号同步，切换项目和重新登录后仍保留；不进入策划发布历史。普通输入框保留原生撤销与剪贴板操作，中文组合输入不触发快捷键；Tab、方向键和 Esc 不可改绑。实际执行与界面提示统一引用 shortcutDefinitions；内置默认中的 Mod 在 Windows 对应 Ctrl，在 Mac 对应 Cmd。段落结构、表格单元格导航等编辑器内置按键暂不提供改绑。

## 富文本故障与源码恢复

正文提供“编辑 Markdown 源码”入口；富文本初次加载或编辑器渲染失败时自动进入源码模式，显示服务端的可安全公开原因和请求编号。未知异常不向浏览器暴露堆栈、路径或敏感数据，可提供请求编号协助排查。

写作期间的同步异常不会强制切换源码或替换当前正文。旧响应自动忽略，重复增量只应用尚未接收的部分；短暂断网或服务故障会保留编辑区并自动重试，可以继续输入。同步记录缺失或远端修改会导致本机输入被丢弃时，暂停同步，不自动覆盖任一版本，并提供“重试同步”和“下载当前正文”。下载包含点击时编辑区的最新内容。提示同步暂停时请勿关闭页面，未同步正文不等于已保存到服务器。

源码模式不依赖富文本解析，使用“保存源码”显式保存；沿用正文存储的末尾空白规范，保存后以服务端实际值为准。即使仍不能渲染，源码也可保存，并进入原有撤销历史。修正后可以“尝试富文本编辑”。这不是发布操作。

未保存源码保留在本机；富文本未确认输入另作恢复副本，不会自动覆盖服务端内容。出现并发冲突时展示最新源码，手工合并并确认保存基线；结果不确定时锁定当前请求，仅允许重试确认，避免重复写入。源码保存仍受账号权限和 Agent 控制权约束，也可下载源码副本。

富文本恢复副本只随正文变化更新，连续输入合并写入；页面转入后台、离开页面或发生同步故障时立即补齐。服务端确认保存后取消待写副本；重新打开时，若副本解析后的内容与已保存正文一致，自动清除，不要求人工核对。不一致的旧副本仍保留供恢复，不会擅自覆盖当前内容。本机副本不是跨设备备份，浏览器或系统突然崩溃时仍可能丢失尚未写入的最后一小段输入。

## 阅读与表格

顶部的返回、前进按钮在工作台内部的页面、集合视图和功能页之间导航。常见鼠标的后退／前进侧键也使用这份站内历史；返回后另开页面会建立新的历史分支。切换前先保存编辑内容，保存失败时保留当前页面和输入。

文档记录阅读段落附近的位置，集合视图记录纵向和表格横向位置。通过链接或侧栏再次打开页面、前进后退以及刷新时自动恢复；正文查找优先定位搜索结果。记录保存在当前浏览器标签页的会话存储中，按账号、项目和草稿隔离，不会同步到其他设备。没有站内历史时，工作台导航按钮和可被网页接收的侧键不会继续后退；鼠标驱动映射的系统级命令仍取决于浏览器和驱动。

集合的文本字段自动换行并随内容增高，不截断后文。Enter 换行，Ctrl+Enter（Mac 使用 Cmd+Enter）完成编辑，也可以移开焦点自动保存；数字、日期和选项仍使用各自的输入控件。

正文工具栏“插入”下拉栏中的“表格”，或斜杠命令“插入 Markdown 表格”，会创建三列表格。鼠标靠近表格边缘时才显示对应按钮与提示，不需要先选中单元格：

- 表格底部、右侧的加号分别追加行、列；表格上方和左侧的点状按钮打开当前列、行的操作菜单。
- 边缘菜单作用于鼠标所在行或列，支持插入、删除、移动和列对齐；鼠标移开后隐藏。键盘导航和无悬停能力的触屏保留表格工具栏。
- Tab / Shift+Tab 切换单元格，最后一格按 Tab 自动新增一行；Ctrl+Enter（Mac 使用 Cmd+Enter）离开表格进入正文。
- 表头固定在第一行，不能通过行操作移动或删除；至少保留一行正文和一列。删除整表使用工具栏的垃圾桶按钮并确认。
- 操作自动保存为 Markdown，并支持原有撤销／重做。只读文档嵌入和集合视图不显示这套 Markdown 表格编辑控件。

深色主题使用中性黑灰层级；表格用顶线、表头分隔线、底线和淡竖线增强结构，集合视图另保留轻量行线。

## 插入图片

在正文粘贴截图、拖入图片文件，或使用正文工具栏“插入”下拉栏中的“图片”和斜杠图片命令。支持静态 PNG、JPEG、WebP，每张不超过 10 MiB、4000 万像素，一次最多处理 5 张。上传时显示临时缩略图，失败可重试或取消；上传未处理完毕时暂不允许离开文档，以免丢失插入位置。

图片按原始字节保存，不压缩、不去除原始元数据，分享前请自行检查敏感信息。正文使用稳定附件地址，不保存 Base64 或临时 blob 地址。单击图片可替换、编辑替代文字或移除，双击查看原图，可切换适应窗口与原始尺寸。操作支持正文撤销／重做。

草稿图片仅上传者可读，合法发布引用后同项目有阅读权限的成员可读；移除引用不删除附件，以保留撤销和历史。暂不自动清理未引用附件。包含本地附件的文档导出为 ZIP，内含 Markdown 与相对路径图片（图片合计最多 50 MiB）；不代为下载外部图片。

图片 ZIP 导出在服务端分块读取和传输，独立限制同时导出的数量；繁忙时可稍后重试，不占用图片上传名额。开始传输前检查附件权限、大小及文件状态，附件缺失时返回可读错误；传输中断后停止读取并释放名额。

### 导出 PDF

标题下方「导出」仍可直接下载 Markdown；点击旁边的下拉箭头，选择「导出 PDF…」。弹窗提供纸张、横纵方向、字号、目录、页码及文档属性设置，并用内置阅读器显示真实 PDF，支持翻页、适合页面及 50%–200% 缩放，不依赖浏览器 PDF 插件。下载的是预览中的同一份文件；可放大预览，设置变更后会重新生成，取消或关闭弹窗会停止本次生成。排版偏好保存在本机，不修改正文或视图。

导出先确认编辑保存，再固定当前工作区的文档、字段和记录快照；不会发布设计。已发布的相同内容标注正式版本，否则标注个人草稿。预检期间内容发生变化时，需点击「刷新快照并重试」，不自动混入新版本。只读账号可以导出其有权阅读的内容。

嵌入文档默认展开一级，不递归展开其中的嵌入。集合视图保留搜索、筛选、排序、可见字段和记录名称，导出全部匹配记录，不受界面分页限制，不展开记录正文。默认跟随表格、列表或卡片布局；可逐嵌入改为统一表格或仅标题链接。相对日期筛选使用固定的导出时间与浏览器时区。引用字段输出可访问目标的名称，而非内部 ID。

外部图片不由服务端自动抓取；附件缺失、引用不可用或公式渲染失败时必须明确确认，文件会保留缺失标记或公式源码。单个视图最多展开 2000 条，所有视图合计最多 5000 条，最多 100 个嵌入块，图片合计最多 50 MiB，PDF 文件最多 30 MiB；超限会提示调整范围，不静默截断。可改为仅保留链接；链接指向工作站，仍要求登录和项目权限。

表格跨页重复表头，长文本与代码换行；字段过多时应选择横向或列表，预览确认可读后再下载。PDF 使用浅色打印排版，不随工作站深色主题变为黑底。

## 合入团队正式版本

团队发布新版本后，个人草稿不会被静默覆盖。工作区顶部会显示警示底色和“合入最新正式设计”按钮。此操作只更新自己的草稿，与发布个人修改相互独立。

合并页显示正式版本的更新内容，无冲突时确认即可合入。发生冲突时，左侧列出冲突项，右侧对照共同基线、个人草稿和最新正式设计。正文支持逐冲突块选择或手动编辑，非冲突内容自动保留；结构化字段可选择一方，也可输入自定义 JSON 值。所有冲突解决后才能提交。草稿或正式版本在此期间变化会阻止提交，重新检查版本会清除本页选择。

页面的 Tips 可复制精简的 Agent 合并指令，使用已安装的协作 Skill，并按 references/publishing.md 的合并小节操作，无需 MCP。帮助仅在缺少契约时读取。review 的 incoming 回执用于确认影响范围，conflictDetails 回执须检查全部分页；自动合并且无冲突的内容无需重读全文。只补读冲突、决策依赖或用户明确要求审查的内容。大值按 read/next 从固定版本分段读取；自定义正文必须包含完整合并结果，不能只提交冲突块。

MCP 的 workspace_read 空参只返回连接概况，指定目标后按字段或范围有界读取；workspace_search 返回元数据及指定字段，不附全文。design_preview 默认返回 review 差异页与各类数量，可按 section 查看 incoming、conflicts 或 diagnostics，并用 next 保留版本前提续页。大值提供 workspace_read 参数；携带 expectedHead 的读取由服务端校验当前草稿，范围 next 保留此前提，列表游标也绑定此前提；草稿变化后续读会拒绝。未携带此前提的固定版本或快照读取仍可用于历史审查。这限制的是 Agent 接收的上下文，服务端仍计算完整预览。Skill 的 help versions / help inspiration 仅列操作入口；使用 help versions.refresh 等查看单项契约，确需完整契约时才用 .full。

分析完成后，用 new-task 创建任务，再用 versions 的 refresh 操作提交原预览的 review 句柄和 resolutions，并携带 --task ID。resolutions 按冲突路径指定 ours、theirs，或 {"value": 自定义结果}；正文自定义结果必须是完整正文，而不是单个冲突块。提交仍受版本校验、数据校验、幂等重试和写入控制保护。业务语义不明确时应先向用户确认，版本过期时重新 review 并重新核对，完成后执行 release --task ID 释放写入控制权，不要擅自发布。

## Agent 协作

通过账号条中的设置打开 Agent 接入。只授予任务需要的权限；共享灵感、发布和实现同步需要分别授权。

复制按钮会优先自动复制，并兼容临时 HTTP 部署；如果浏览器仍不允许，会展示已全选的完整内容，供手动复制。复制后点击“我已复制”确认；取消或关闭不会将凭据标记为已复制。密钥只应粘贴到可信位置。

Agent 首次写入时取得草稿控制权，在一个任务内持续使用会话，结束后释放。浏览器会提示 Agent 正在写入，并实时展示保存的修改。

人工可以收回控制权。被收回的会话不能继续写入，Agent 必须明确重新申请；不要把重试网络请求当作重新授权。

有未保存输入的页面失联后，系统不会自动忽略它。超过 30 秒未报告在线状态时，自己的草稿页面会提示最后在线时间：优先回到原页面保存；确实无法恢复时，可以经确认放弃该页面的未保存输入保护，解除 Agent 交接及项目管理的相关阻塞。此操作不保存未上传的输入，也不删除本地恢复副本；页面重新上线后仍会重新报告状态。其他账号及 Agent 不能代为确认。

## 发布与实现同步

在“发布变更”按文件检查差异，可以丢弃无意改动，也可以撤销误操作。填写说明并发布后，团队得到新的正式设计版本。发布准备期间仍可浏览其他内容；如果准备期间草稿、团队正式版本、权限或控制权发生变化，系统会重新检查并拒绝不再满足条件的发布，不会用旧预览覆盖新修改。

“发布记录”展示已发布的更新及实现同步状态。“待同步至实现”表示还需要判断代码是否要调整；“已确认同步至实现”表示获授权的成员或 Agent 已确认对应实现，可以同时填写代码仓库、提交和说明。这不是平台自动检查代码得出的结论。

## 共享灵感

灵感池是项目共享便签，不进入草稿发布、设计版本或实现同步流程。Agent 不会通过普通设计搜索读取它，需要独立的灵感权限和入口。

可以把灵感复制到草稿继续整理；复制后原便签保留，两者不会双向同步。

## 账号与权限

每个浏览器标签页独立选择项目；一个标签页切换项目，不会改变其他标签页的保存目标。

侧栏账号条收纳设置、项目切换和退出；设置中可以修改密码、主题、语言及 Agent 凭据。改密后需重新登录，原登录会话和 Agent 凭据失效。

管理员通过 /admin 管理账号、项目和授权。界面中的删除不等同于彻底擦除所有历史数据；敏感数据的保存与备份由部署者管理。
