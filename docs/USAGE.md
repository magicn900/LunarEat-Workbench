# 使用指南

## 我的草稿

每个账号在每个项目中都有自己的草稿。页面和结构化集合都属于草稿；编辑会自动保存，尚未发布的内容不会成为团队正式设计。

用页面顶部工具栏插入链接、文档或集合视图，也可以在空段落输入 /，再搜索和选择命令。视图中的编辑直接修改原对象，不会生成另一份数据。列头漏斗可以筛选、排序，视图底部可以调整分页。

右键菜单提供相关操作；Ctrl+Z 撤销，Ctrl+Shift+Z 重做。人工和 Agent 修改都进入同一套内容历史。同一编辑过程被其他页面的修改打断时，会拆成独立撤销步骤，避免撤销其他页面的内容。若已有历史记录混入了其他页面的修改，系统会拒绝不安全的撤销或重做；可以在“发布变更”中逐项检查并丢弃需要恢复的内容，不会自动重写历史。

## Agent 协作

通过账号条中的设置打开 Agent 接入。只授予任务需要的权限；共享灵感、发布和实现同步需要分别授权。

Agent 首次写入时取得草稿控制权，在一个任务内持续使用会话，结束后释放。浏览器会提示 Agent 正在写入，并实时展示保存的修改。

人工可以收回控制权。被收回的会话不能继续写入，Agent 必须明确重新申请；不要把重试网络请求当作重新授权。

有未保存输入的页面失联后，系统不会自动忽略它。超过 30 秒未报告在线状态时，自己的草稿页面会提示最后在线时间：优先回到原页面保存；确实无法恢复时，可以经确认放弃该页面的未保存输入保护，解除 Agent 交接及项目管理的相关阻塞。此操作不保存未上传的输入，也不删除本地恢复副本；页面重新上线后仍会重新报告状态。其他账号及 Agent 不能代为确认。

## 发布与实现同步

在“发布变更”按文件检查差异，可以丢弃无意改动，也可以撤销误操作。填写说明并发布后，团队得到新的正式设计版本。发布准备期间仍可浏览其他内容；如果准备期间草稿、团队正式版本、权限或控制权发生变化，系统会重新检查并拒绝不再满足条件的发布，不会用旧预览覆盖新修改。

“发布记录”展示已发布的更新及实现同步状态。“待同步至实现”表示还需要判断代码是否要调整；“已确认同步至实现”表示获授权的成员或 Agent 已确认对应实现，可以同时填写代码仓库、提交和说明。这不是平台自动检查代码得出的结论。

## 共享灵感

灵感池是项目共享便签，不进入草稿发布、设计版本或实现同步流程。Agent 不会通过普通设计搜索读取它，需要独立的灵感权限和入口。

可以把灵感复制到草稿继续整理；复制后原便签保留，两者不会双向同步。

## 账号与权限

每个浏览器标签页独立选择项目；一个标签页切换项目，不会改变其他标签页的保存目标。

侧栏账号条收纳设置、项目切换和退出；设置中可以修改密码、主题、语言及 Agent 凭据。改密后需重新登录，原登录会话和 Agent 凭据失效。

管理员通过 /admin 管理账号、项目和授权。界面中的删除不等同于彻底擦除所有历史数据；敏感数据的保存与备份由部署者管理。
